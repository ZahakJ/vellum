[[ Vellum ]]

Your notes, published beautifully.

View on GitHub Quickstart

An Obsidian-style vault that is also a website engine

Point it at a folder of plain Markdown. Edit like Obsidian. Publish like a blog.

Publish mode

Mark any note publish: true and it becomes part of your public site — magazine dashboard, topic navigation, RSS, and reader comments. Everything else stays private.

Your vault as a constellation

A force-directed graph of every wikilink, interactive at thousands of notes, plus a live local graph beside each note.

Four themes & full theming

Iron-gall, void, lapis, parchment — then make it yours: site name, logo, favicon, custom CSS and fonts, all from an in-app settings panel.

Marginalia

Readers can leave notes in the margins of your published pages. You moderate with one click.

Everything from the keyboard

Command palette, quick-switcher, slash menu, vim mode, daily notes, paste-to-upload images.

Lovely on every screen

The public site is fully responsive; RTL languages and KaTeX math render beautifully everywhere.

Quickstart

Node ≥ 22, no database, no build step for your notes.

# run it
git clone https://github.com/ZahakJ/vellum.git && cd vellum
npm install && npm start
# point it at your existing Obsidian vault
VELLUM_VAULT=~/notes npm start
# lock it down & publish
npm run hash-password   # → ADMIN_PASSWORD_HASH in .env

Feature ledger

Everything ships in the box.

  • CodeMirror 6 live-preview editor
  • Wikilinks, backlinks, transclusions
  • Callouts, KaTeX, code highlighting
  • Note banners with generated fallbacks
  • Full-text fuzzy search (Ctrl+K)
  • Selective publishing + visitor preview
  • Blog mode: dashboard, topics, RSS, sitemap, SEO
  • Reader comments with moderation
  • argon2 admin auth, rate-limited
  • Settings panel — no config files needed
  • Deep links, SSE live reload
  • RTL + unicode vaults, tested at 1.4k notes
