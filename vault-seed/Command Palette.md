# Command Palette

`Ctrl/Cmd P` opens the palette — one keystroke between you and anything in the
vault. #guide #keyboard

Start typing and it fuzzy-matches note titles; press Enter to open. With no
query it shows commands and recent notes, so the palette doubles as a launcher:

- **New note** (also `Ctrl/Cmd N`)
- **Toggle graph** (also `Ctrl/Cmd G` — see [[Graph View]])
- **Theme: …** — one command per look, fifteen of them: eleven dark rooms (*iron-gall*, *cinnabar*, *sumi*, *void*, *basalt*, *nocturne*, *lapis*, *verdigris*, *moss*, *porphyry*, *tallow*) and four lit ones (*parchment*, *sandstone*, *solar*, *linen*). To browse rather than jump, open the theme picker from the status bar and walk it with the arrow keys — it previews live and Esc puts back what you had.
- **Toggle vim** — modal editing, as promised in [[Editing]]
- **Rename current note** — safely; links update, as explained in [[Wikilinks & Backlinks]]
- **Delete current note**

Navigate with ↑ ↓, confirm with Enter, dismiss with Esc.

## The whole keymap

| Keys | Action |
| ---- | ------ |
| `Ctrl/Cmd P` | Command palette |
| `Ctrl/Cmd N` | New note |
| `Ctrl/Cmd G` | Toggle graph view |
| `Ctrl/Cmd S` | Save now (autosave already has your back) |
| `Ctrl/Cmd`-click | Follow a [[Wikilinks & Backlinks|wikilink]] |
| `Esc` | Close palette |

That's the entire app surface. If your hands ever leave the keyboard, it's
because you're dragging nodes around the [[Graph View]] for fun — or because
you started at [[Welcome]] and are clicking through the tour.
